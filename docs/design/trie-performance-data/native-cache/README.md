Enabling the same hash features as the node does not make this an end-to-end node benchmark. Input values repeat unchanged across samples, and fixture/reference hashing plus warmup populate the shared hash cache; no cache hit ratio is collected. Alloy's default cache has 131,072 buckets (about 16 MiB), caches inputs up to 87 bytes on this 64-bit host, and bypasses longer inputs. Each process starts a fresh cache, but samples/cases within it reuse that cache. The harness uses the system allocator rather than node jemalloc. Production blocks have a changing mix of inputs and contention. Interpret the matrix as a repeated-fixture, warm kernel check.
